# 系统设计

先练与 CaseHub、auto-test 有交集的六个通用设计问题：异步任务、中断、重复请求、变化中的知识、AI 产物上线和端到端质量工程。前五个主题使用其他业务场景来练迁移能力，第六个可以直接用项目。之后练数据、业务事件、热门内容、突发流量、故障排查和多租户等通用题。每周练两个场景。点击“AI 生成系统设计题”会调用本地 CLI；前六个主题还会读取相邻仓库文档作为设计背景。题干只给业务背景、需求和客观条件，不预设架构或技术方案。

每次练习先澄清需求，再用页面上的组件和连线画架构图，按[答题格式参考](answer-guide.html)写下规模、接口、数据、主流程、故障处理和取舍，逐项回答追问。页面自动保存方案和图；“AI 评估方案”会给出评分、具体缺口、追问反馈和下一次练习方向。评估只基于写入页面的内容；口头解释也应简要记下，避免凭空被评分。复盘记录保存在 `data/progress.json`。

CLI 配置见根目录 [README](../README.md)。本地仓库文档只为前六个主题提供设计灵感；AI 的项目事实和改造建议仍需回到代码或文档核对。

如果已生成的题目直接给出解决方案，可点“换一道题”。旧题目和已写的方案会保存在当前主题的历史记录中；新题生成失败时原题不会被替换。
