# 算法编码

从总站进入算法编码。先选六个类别之一，再选难度并点击“AI 生成新题”。同一类别可以反复生成不同题目；页面不会提前展示固定题名。题目保存在 `data/progress.json`，以后可逐题复练。

每周建议 3–4 道新题、1–2 道复练题，两个月覆盖数组与字符串、哈希表、双指针、二分、栈与队列、基础树遍历。先口述思路和复杂度，再限时写 Python。代码草稿停止输入后自动保存。写完在本机运行示例与边界输入，把结果填到页面，点击“AI 评估代码”。AI 只审阅提交的文本，不运行代码；评估会指出可能的错误、复杂度和下一步测试。保存本次练习后，连续两次自测“独立写对”会标为“稳定通过”。

CLI 配置见根目录 [README](../README.md)。练习记录与 AI 评估都保存在 `data/progress.json`，可随 git 历史保留。
