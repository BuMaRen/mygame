# English

在 practise 根目录运行 `npm start`，然后打开 http://localhost:4600/english/ 。每天从"今日"页开始。

## 目标

- **读**：能顺畅读懂技术文档、GitHub issue/PR、技术博客、工作邮件，以及日常的文章、社交媒体帖子、聊天消息，不靠逐句翻译。
- **写**：能用简单清楚的英文做基本回复。工作上：issue 评论、PR review、邮件；日常闲聊：打招呼、聊近况、聊兴趣、约时间。
- **不做**：应试、背难词、刷语法题、追求口语发音。

起点：以前有点基础，但单词和语法基本忘光。所以先用 4 周把"够读懂"的地基捡回来，之后用大量真实阅读（技术 + 日常）和闲聊对练代替背书。

## 原则

1. **在语境里学词，不背词表。** 读到不认识的词才记，只记会反复出现的。
2. **语法只学阅读用得上的 8 个点**，目标是能拆长句，不是做选择题。
3. **两条线：技术 + 日常。** 技术线读你本来就要读的东西，学英文和干活合并；日常线读你本来就感兴趣的东西，闲聊用的词和句型只能从这里来。
4. **工作日每天少量，周末休息。** 每个工作日 30 分钟。漏了一天不补，第二天照常做当天的内容。
5. **先读懂再求快。** 第一遍不查词，读完一段再查，逼自己猜。
6. **AI 当陪练，不当翻译器。** 让它出题、改句子、解释结构，而不是把整段翻成中文。

## 每周安排

| 周一 | 周二 | 周三 | 周四 | 周五 | 周末 |
|------|------|------|------|------|------|
| 技术 | 日常 | 技术 | 日常 | 技术 + 周回顾 | 休息 |

哪条线明显更弱，就把一天换成那条线。

## 阶段

| 阶段 | 周 | 重点 | 结束标准 |
|------|----|------|----------|
| 1 捡回地基 | 1–4 | 每周 2 课语法 + 短篇阅读 + 1–2 句写作 | 一段 Playwright 文档能说出每句主干；平均每句不到 1 个生词；能用英文做自我介绍、聊 3 句今天干了什么 |
| 2 阅读量 | 5–12 | 每天一篇真实材料，写总结，跟 AI 闲聊 | 约 1500 词的技术博客不翻译读完，能写 3 句英文总结；跟 AI 连续闲聊 10 轮不卡壳 |
| 3 真实场景 | 13–24 | 读工作里真实要读的；真的发 issue、评论、PR 描述；跟真人文字闲聊（英文社区回帖，或 HelloTalk / Tandem 这类语伴 App） | 日常英文资料默认读英文；能独立写清楚一条 issue；跟真人文字闲聊时不用先打中文草稿 |

## 每日计划怎么来

每个工作日第一次打开"今日"页时，本地服务器会调用所选的 **Claude 或 Codex CLI**（仅生成文本，不开放工具）生成当天的计划。生成时会给它三类信息：

- **计划框架**：每周安排、三个阶段的重点和结束标准、阶段 1 默认的语法进度、学习原则。见 `js/plan.js`。
- **资料**：语法课列表、阅读材料库、AI 陪练提示词、可以链接的页面。见 `content/`。
- **训练情况**：最近 5 个工作日的打卡和缺勤、前几天的计划和完成情况、每课语法学完没有和练习对错、正在学的生词、阅读记录里"懂了多少"、写作日志里学到的点、最近一次周回顾。见 `data/`。

生成的内容包括：今天的重点、根据训练情况做了哪些调整、任务清单、今天的阅读材料，以及写作 / 闲聊题目。

**阅读材料由系统挑，不用自己找。** 技术线改编真实来源（工具文档、issue、release notes、技术博客）；日常线写地道的母语者日常文字（帖子、消息、评论）。读的时候把不认识的词点出来，系统据此算出每篇的生词率，并累计你"读到且认识的词"。之后的材料按生词率调整难度和篇幅：目标是 2%–5%，高于 8% 就变简单变短，低于 2% 且懂得多就加难度。

计划和材料分别保存在 `data/plans/<日期>.json` 和 `data/materials/<日期>.json`。**一天的计划和材料生成后就固定了**：服务器只在文件不存在时创建，之后不会再生成，也不会覆盖。同时点两次只会调用一次 CLI。周末不生成计划。

| 环境变量 | 作用 | 默认 |
|----------|------|------|
| `PRACTISE_AI_CLI` | 选择 `claude` 或 `codex` | `claude` |
| `PRACTISE_CLAUDE_BIN` / `PRACTISE_CODEX_BIN` | 对应命令的路径 | `claude` / `codex` |
| `PRACTISE_CLAUDE_MODEL` / `PRACTISE_CODEX_MODEL` | 对应 CLI 的模型 | CLI 默认模型 |
| `PRACTISE_AI_TIMEOUT_MS` | 单次生成的超时（毫秒） | 300000 |

阅读页点评英文总结也走同一个 CLI（每次约 20–60 秒），点评结果存进 `data/reading.json` 的那条记录，被纠正的点会作为下一天生成计划时的参考。

前提是本机能运行所选的 `claude` 或 `codex` 命令，并已登录。生成时间与费用取决于所选 CLI 和模型。

## 页面

| 页面 | 做什么 |
|------|--------|
| 今日 | 本地 AI 生成的当日计划：任务清单、今日阅读材料、写作题目；打卡、统计、阶段进度、历史计划。从任务进入练习页后，页面顶部会出现"今日计划"条，可以"完成，回到计划"（同时勾掉这项任务）或直接回到计划 |
| 语法 | 8 课：讲解、例句、练习（先写答案再看参考）。找难句、拆长句放在阅读环节做 |
| 词汇 | 闪卡复习（连续 3 次都懂就变成熟词）、生词本、种子词表（技术 / 日常，点"加入"弹窗确认，留在原页面）、每周小测提示词 |
| 阅读 | 今日材料：通读并点出生词 → 看生词表、做理解题 → 记录（懂了多少、英文总结、最难的一句）。保存后本地 AI 会点评英文总结：理解准不准、逐处纠错、改正后的版本、更地道的写法、一个要记住的点；可以改写后再评，也可以一键存进写作日志。另有阅读记录和词汇量（生词率走势、认识 / 不认识的词） |
| 写作 | 写作日志（原句 → AI 改后 → 学到什么）、工作句型、闲聊句型（点击复制） |
| AI 陪练 | 提示词模板：填好空格后复制，贴给 Claude 或 Codex |
| 进度 | 工作日打卡日历、周回顾、阶段达成登记 |

## 文件

| 路径 | 内容 |
|------|------|
| `*.html` | 各个页面 |
| `content/*.js` | 课程内容：语法、词表、句型、阅读来源参考、提示词。改内容就改这里 |
| `js/lexicon.js` | 从阅读标记统计词汇量（浏览器和服务器共用） |
| `js/plan.js` | 计划框架：每周安排、阶段划分、日期计算（浏览器和服务器共用） |
| `api.mjs` | 生成每日计划：整理训练情况 → 调用所选 AI CLI → 固定保存 |
| `js/common.js` | 导航、读写数据 |
| `data/*.json` | 你的练习记录（第一次保存时生成），记得提交 |
| `data/plans/*.json`、`data/materials/*.json` | 每天生成的计划和阅读材料，生成后不再改动 |
