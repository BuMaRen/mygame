# 九州行军录

一款可直接在浏览器中玩的像素风三国策略原型。地图操作参考 GBA 时代俯视游戏，城池经营、武将、招兵和统一天下构成游戏循环；战斗直接在战略地图上结算。

## 运行

运行 `./start.sh`，然后访问 `http://localhost:38471`。可用 `PORT=其他端口 ./start.sh` 指定端口。无需安装依赖。游戏会自动在浏览器本地存档，也可点击“存档”。

## 玩法

- 选择我方城池，每月可执行两条指令：开发农业、发展商业、征兵、筑城、寻访武将、训练士气、调任武将、出征调兵。
- 金钱和军粮按月产出；军队每月消耗军粮，断粮会损失兵力和士气。
- 只能沿地图道路前往相邻城池。调兵可支援我方城池；进攻敌城依据兵力、武将武力、士气、城防及少量随机因素即时结算。
- 曹操军和孙权军每月经营城池并可能进攻。占领全部 14 座城池获胜。
- 点击城池，或用方向键 / WASD 切换选择；`N` 结束本月，`Esc` 关闭弹窗。

## 当前范围

这是单人可玩的首版。世界采用 14 座城市、24 名初始武将与 6 名在野武将；地图、剧情、武将技能、外交和更细的兵种系统可在此基础上继续扩展。
